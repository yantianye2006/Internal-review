# 统一问题账本

## 问题字段

每条问题包含：

```text
问题编号
来源模块
位置
严重度
核验状态
问题事实
证据或依据
影响范围
修改建议
修复条件
修复状态
关联问题
```

位置至少使用章节、标题、段落开头、页码、公式编号、图表编号或参考文献编号之一。

## 编号

```text
通-01  通用内部质量与跨章节问题
摘-01  摘要问题
述-01  问题重述问题
析-01  问题分析问题
假-01  模型假设问题
符-01  符号说明问题
参-01  参考文献元数据问题
引-01  正文论断支持与引用缺失问题
```

每个模块独立递增。编号在检查、修改和复核过程中保持稳定；修复后保留记录并更新状态，
新增根因使用该模块下一个未用编号。专家直接调用产生的编号进入后续父 Skill 账本时不得重排。

## 合并与去重

1. 专家对本领域拥有优先诊断权，父 Skill 不复制内容相同的问题。
2. 同一根因保留一个主问题，其他表现写入证据、影响范围或关联问题。
3. 不同根因即使位于同一位置也分别编号。
4. 摘要与正文冲突归 `通-*`，摘要内部缺陷归 `摘-*`。
5. 重述遗漏题意归 `述-*`；正文因此未完成任务时另建 `通-*` 并关联。
6. 参考文献元数据错误归 `参-*`；论断支持不足或引用缺失归 `引-*`；纯排版格式归 `通-*`。
7. 专家结论冲突时保留证据并标记“需作者确认”，不自动选择更有利或更严厉的结论。
8. 没有问题时记录模块通过，不制造问题。

## 状态更新

- `未处理 -> 已修复`：授权修改完成且定向复核通过。
- `未处理 -> 部分修复`：授权范围只解决部分根因或依赖尚未处理。
- `未处理 -> 仍需材料`：缺少继续判断或修改所需材料。
- `未处理 -> 需重新计算`：文字修改不足以解决结果或模型问题。
- `未处理 -> 需作者确认`：存在无法由现有证据消解的选择或冲突。
- 复核否定原判断时保留编号，并将核验状态改为“已排除”。

问题记录不得因排序变化或输出语言变化而重新编号。
