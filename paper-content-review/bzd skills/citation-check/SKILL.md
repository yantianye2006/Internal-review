# Citation Check

本专家由 `nature-citation` 的论断拆分、检索和证据分级框架适配而来，可由 `paper-content-review` 编排，也可直接检查或修订指定引用范围。参考文献作者、题名、年份、卷期页码和 DOI 等元数据真实性由 `nature-ref-verifier` 使用 `参-*` 处理；本专家只使用 `引-*`。

开始前读取：

- [../../references/review-contract.md](../../references/review-contract.md)
- [references/evidence-rules.md](references/evidence-rules.md)

## 门禁与定位

具体论断、引用段落，或能够建立正文—文献对应关系的内容任一存在即可开始。完整论文、题面、格式规范和可访问外部来源用于扩展覆盖、格式与证据强度核验；缺少时仅把相应判断标为“待核实”或“无法核验”，不冻结局部检查。

本专家使用 `引-*` 和 P0—P3。编排调用时只向 `paper-content-review` 返回问题候选与模块状态；直接调用时可增加简洁的引用模块结论和材料限制。

## 审查范围

1. 定位正文中的现有引用、文末参考文献和需要证据的关键论断。
2. 检查正文引用与文末条目是否一一对应，编号或作者—年份体系是否内部一致；格式规则存在时再核对指定格式。
3. 将关键论断拆成可检索 claim，判断现有文献是否提供强支撑、部分支撑、背景支撑、限制性证据或仅主题相关。
4. 检查是否用相关主题文献替代直接证据、用综述替代可获得的原始研究、把相关性写成因果，或超出研究对象和条件。
5. 检查研究背景、方法选择、数据来源、强假设和关键比较是否存在重要引用缺口。
6. 元数据疑点建立或关联 `参-*` 任务，不在本模块冒充已完成真实性核验。

## 证据原则

- 默认不限出版社或期刊品牌，以论断匹配度、证据质量和来源可识别性排序。
- 优先使用结构化元数据、出版方页面、权威数据库、摘要或全文；搜索结果摘要只能用于发现候选。
- 题名相关不等于支持论断，元数据候选不得直接当作证据。
- 不编造作者、题名、期刊、年份、DOI、页码、结论或缺失字段。
- 医疗、安全或时效性论断应使用当前来源并保守表达。

## 输出约束

- 每条问题使用 `引-*`，并按统一问题字段返回。
- 在“问题事实”中注明类型：`对应关系 / 支持不足 / 引用缺失 / 过度表述 / 格式`。
- 没有问题时返回“引用模块通过”，不得制造问题。
- 不生成 HTML、TSV、JSON、RIS、ENW、RDF、BibTeX Patch 或 Zotero 指令。
- 不把检索结果直接写入论文；补引用或改写必须等待用户授权具体问题编号或范围。
- 直接 `revise` 时只处理用户指定的 `引-*` 编号、论断或引用段落；新增来源必须真实可核验，改写不得扩大原文结论强度。
- 修订影响参考文献表、编号顺序或其他章节时，列出依赖并等待额外授权。

当外部来源不可访问时，保留论文内部能够确认的引用问题，把真实性和支持强度标为“无法核验”。
